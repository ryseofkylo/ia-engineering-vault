## Experimento 1 · Medí tu esquema en tokens

**Corresponde a:** §1.1 – §1.3 · **Tiempo:** 20 minutos

**Objetivo.** Convertir "el esquema es grande" en un número.

```python
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")

ddl = open("una_tabla_real.sql", encoding="utf-8").read()
ids = enc.encode(ddl)

print(f"caracteres: {len(ddl)}")
print(f"tokens:     {len(ids)}")
print(f"ratio:      {len(ddl)/len(ids):.2f} caracteres por token")

for nombre in ["CLIENTENRO", "CONTRATONRO", "dbo.Contratos", "customer_id"]:
    print(f"{nombre:>15} → {[enc.decode([i]) for i in enc.encode(nombre)]}")
```

**Qué anotar**
- Tu ratio de caracteres por token. La referencia para inglés es ~4; el tuyo va a ser peor.
- Cuántos tokens ocupa un `CREATE TABLE` promedio.
- Cómo se parte `CLIENTENRO`.

**La pregunta a responder:** si tu ventana son 8K tokens y reservás 800 para la respuesta, **¿cuántos fragmentos de esquema podés mandar realmente?**

## Experimento 2 · Reproducí la curva en U con tu esquema

**Corresponde a:** §1.5 · **Tiempo:** 1 hora

**Objetivo.** Ver con tus datos el efecto de la posición.

**Montaje**
1. Elegí 20 preguntas cuya respuesta requiera **una** tabla específica y conocida.
2. Para cada una, armá una lista de 10 fragmentos: el correcto más 9 distractores (tablas parecidas — lo que tu retriever va a devolver igual).
3. Corré tres condiciones: el fragmento correcto en la **posición 1**, en la **5** y en la **10**.
4. Medí en cuántas de las 20 el SQL generado usa la tabla correcta.

```python
for pos in [0, 4, 9]:
    aciertos = 0
    for pregunta, correcto, distractores in casos:
        fragmentos = distractores[:]
        fragmentos.insert(pos, correcto)
        sql = generar_sql(pregunta, fragmentos)
        aciertos += usa_tabla_correcta(sql, correcto)
    print(f"posición {pos+1:>2}: {aciertos}/20 = {aciertos/20:.0%}")
```

**Qué anotar.** Los tres porcentajes: ¿se ve la U? Y agregá los dos baselines de §1.5: closed-book (sin ningún fragmento) y oracle (sólo el correcto).

**La pregunta a responder:** ¿en qué posición pega hoy tu retriever el fragmento correcto, en promedio?

## Experimento 3 · La temperatura, a mano

**Corresponde a:** §1.7 – §1.8 · **Tiempo:** 10 minutos

**Objetivo.** Que la fórmula deje de ser abstracta.

```python
import numpy as np

def softmax(logits, T=1.0):
    x = np.array(logits, dtype=float) / T
    e = np.exp(x - x.max())
    return e / e.sum()

for T in [0.5, 1.0, 2.0]:
    print(f"T={T}: {np.round(softmax([1, 3], T), 3)}")
```

**Resultado esperado** — tiene que dar exactamente esto:

```
T=0.5: [0.018 0.982]
T=1.0: [0.119 0.881]
T=2.0: [0.269 0.731]
```

**El extra que vale la pena:** probá con `[1, 1.1]` y con `[1, 10]`. Vas a ver que en el segundo caso la temperatura casi no mueve nada. **La temperatura importa donde el modelo duda, y casi nada donde está seguro.**

## Experimento 4 · Cuánto varía tu SQL

**Corresponde a:** §1.7 – §1.8 · **Tiempo:** 30 minutos

**Objetivo.** Medir tu ruido de fondo **antes** de medir cualquier otra cosa.

```python
for T in [0.0, 0.7, 1.0]:
    for pregunta in preguntas[:5]:
        salidas = [generar_sql(pregunta, temperature=T) for _ in range(5)]
        print(f"T={T} | {pregunta[:40]:<40} | {len(set(salidas))} distintas de 5")
```

**Qué anotar.** Con `T=0`: ¿cuántas respuestas distintas de 5? Si es 1, podés evaluar. Si es más, **ése es tu ruido, y ninguna mejora menor a ese ruido es distinguible del azar**.

## Experimento 6 · El outlier que arruina la escala

**Corresponde a:** §1.16 · **Tiempo:** 15 minutos

**Objetivo.** Entender de primera mano por qué existe la granularidad por grupos.

```python
import numpy as np

def cuantizar_afin(x, q_min=-128, q_max=127):
    val_min, val_max = float(x.min()), float(x.max())
    S = (val_max - val_min) / (q_max - q_min)
    Z = q_min - round(val_min / S)
    q = np.clip(np.round(x / S + Z), q_min, q_max).astype(np.int8)
    return q, S, Z

def error_medio(pesos):
    q, S, Z = cuantizar_afin(pesos)
    recuperado = S * (q.astype(np.float32) - Z)
    return np.abs(pesos - recuperado).mean(), S

pesos = np.random.randn(1000).astype(np.float32)
print("sin outlier: error=%.6f  S=%.6f" % error_medio(pesos))

pesos[0] = 50.0                       # un solo peso atípico
print("con outlier: error=%.6f  S=%.6f" % error_medio(pesos))
```

**Qué anotar.** Cuánto creció `S` y cuánto creció el error medio de los **999 pesos normales** por culpa de **uno solo**.
