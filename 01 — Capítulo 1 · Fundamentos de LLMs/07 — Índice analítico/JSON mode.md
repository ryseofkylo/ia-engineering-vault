# JSON mode

> **En una línea.** Es una opción de la API que garantiza que la salida sea **JSON sintácticamente válido**, pero no garantiza absolutamente nada sobre qué campos tiene ni qué valores traen.

> [!info] Ficha de consulta
> Esto es el índice analítico, no el libro. **El desarrollo completo está en [[1.11 — Del texto libre al dato|§1.11]]**
> y también se lo trata en [[1.12 — Las cuatro estrategias|§1.12]].

---

## La idea, en corto

Activás una bandera y el proveedor se asegura de que lo que sale parsee como JSON. Se acabaron las respuestas con backticks de markdown alrededor o con una frase de cortesía antes.

Lo esencial sobre el JSON mode: **garantiza salidas JSON válidas pero no su contenido**.
